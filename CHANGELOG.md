# Changelog

## 1.0.0-rc.3 — 2026-11-04

- Compact right-side locations with per-type visibility, branch cycling and a separate destination card.
- Consistent Feather location icons, teal destination pins and outlined route rendering.
- Hide streamed entities locally, filter entity-attached trackers and constrain the aerial camera.
- Retry waypoint GPS from the next road node and keep radar calculation active behind the hidden HUD.
- Expanded native-mock and browser checks; document remaining live GPS and two-player verification.

## 1.0.0-rc.2 — 2026-11-04

- Original SH map interface with a floating left discovery panel, teal accents and a bottom control dock.
- Explore, Nearby and Saved filters, place count and a persistent save action.
- Separate destination card, compact location identity and expandable control hints.
- Responsive layout and updated map route/waypoint colors.

## 1.0.0-rc.1 — 2026-11-04

- Public resource name and events: `sh_pauseMenu`.
- Independent map engine and interface; transferred reference-resource files removed from the distribution.
- Server-configurable branding, map locations, sprite labels, colors and optional integrations.
- Native GPS sampling, character-owned saved places, waypoint sharing and camera cleanup.
- English installation guides, MIT code license, third-party notices and automated checks.
