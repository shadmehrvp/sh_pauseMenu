# Changelog

## 1.0.0 — 2026-11-05

- Initial stable release by Shadmehr Valipour.
- English pause menu with configurable branding, settings and character information.
- ESX Legacy, QBCore, Qbox, standalone and custom framework adapters.
- Local character headshots with cleanup and fallback handling.
- Live aerial and 2D maps with a compact SH location interface.
- Searchable public places, branch cycling, visibility controls and destination cards.
- Teal waypoint pins, GPS routes, on-foot route fallback and trip preview.
- Character-owned saved places, sequential stops and GPS sharing.
- Aerial entity concealment, camera limits and public-location filtering.
- Clean installation package, source checks, MIT license and asset notices.
